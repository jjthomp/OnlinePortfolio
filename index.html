01 / 04

Spatio-Temporal EMG Signal Analysis

Developed automated contraction detection and sensor shift analysis for High-Density Surface EMG in stroke rehabilitation — reducing a weeks-long manual labelling process to a single automated script with sub-1% error margin. Applied TKEO-based algorithms, gradient descent optimization, and multi-feature spatial mapping.

MATLAB Signal Processing Optimization Clinical Research

02 / 04

Pediatric Injection Pain Relief Device

Led hardware and firmware development for an open-source, 3D-printable pain-modulation device for children with Juvenile Idiopathic Arthritis. Designed custom PCB motor driver, embedded microcontroller control, and validated performance against clinical specifications — achieving 162 Hz vibration and stable 4.7–7.4°C cooling surface.

PCB Design Embedded Systems CAD / 3D Print V&V Testing
View case study
03 / 04

Fall Detection Algorithm for Older Adults

Built a sensor-agnostic ML pipeline for real-time fall and near-fall detection using IMU data, designed for integration into wearables. Implemented rigorous signal preprocessing, 10-second rolling window segmentation, and a Random Forest classifier with GridSearch cross-validation — prioritizing sensitivity to ensure zero missed falls.

Machine Learning Python IMU / Wearables Feature Engineering
View case study
04 / 04

Bladder Management Device

Co-op research at the BioAugmentative Interfaces Laboratory developing an SMA-actuated implantable bladder management device. Contributions spanned C++ control system firmware, silicone elastomer actuator fabrication, custom test fixture design, BLE communication protocol via Zephyr OS on a custom PCB, and pre-clinical rodent and cadaver validation.
